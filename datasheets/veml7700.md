# VEML7700 peripheral description

Vishay document 84286, Rev. 1.8, 28 November 2024.

Page 6 gives seven-bit address 0x10 and the register-read sequence in Figure 9.
The on-wire address bytes 0x20/0x21 already contain the R/W bit and must not be
used as the host's seven-bit address. The command is one byte; each selected
register returns two bytes, least-significant byte first (pp. 6-7).

| Operation | Peripheral payload sent | Bytes received | Source |
|---|---|---|---|
| configuration_raw | `00` (one byte) | 2 | pp. 6-7 |
| ambient_raw | `04` (one byte) | 2 | pp. 6-7 |

The device defaults to shutdown (p. 7). Raw data can be read while shut down
(p. 6), but fresh ambient measurements require configuration outside this rule
format. No lux conversion or initialization is performed. This PDF contains
inconsistent register-count/address-option descriptions on pp. 6-9; the ID
register is deliberately omitted. The two entries above agree with Figure 9
and the p. 7 register table. Host-tested only; no VEML7700 bench acceptance.
