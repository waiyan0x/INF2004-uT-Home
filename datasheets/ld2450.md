# HLK LD2450 peripheral description

Hi-Link LD2450 serial communication protocol v1.03.

The radar streams ten 30-byte reports per second at the default 256000 baud,
8N1 (PDF p. 12). Each report has a four-byte header, three eight-byte target
records and a two-byte trailer. The raw receive operations transmit zero bytes.
A chunk can start inside a report or span two reports. The caller must check
completion status and the actual RX count. Frame synchronization and target
decoding remain separate. Confirm the module uses the default baud and the
reviewed board RX connection before execution.
