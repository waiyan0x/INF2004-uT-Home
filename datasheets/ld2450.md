# HLK LD2450 peripheral description

Hi-Link LD2450 serial communication protocol v1.03.

**Reference only: UART streaming is outside the current I2C rule format.**

Section 2.3 on PDF p. 12 specifies default baud 256000, one stop bit, no parity,
and reports at 10 frames/second. Reports start with `AA FF 03 00`, contain
three eight-byte target records, and end with `55 CC`: 30 bytes in total.
Receiving a report requires no per-report command. Do not invent a register
byte or an I2C address for this operation.

A later UART implementation must synchronize on frame boundaries and handle
partial frames, timeouts and errors. The 30-byte report also exceeds the present
16-byte response capacity. Configuration commands use a separate envelope
(pp. 6-12) and are not included here. Target interpretation is the user's task;
this description does not implement occupancy classification or repair the
previously observed radar reliability issues.
