# BMP388 peripheral description

Bosch BST-BMP388-DS001-07, revision 1.7 (November 2020).

This describes raw register reads, not pressure measurement setup. Page numbers
below are one-based PDF pages. Pages 40-41 describe I2C mode/address selection
and repeated-START reads. SDO low selects 0x76; SDO high selects 0x77. Do not
leave SDO floating. CSB must select I2C; confirm the board wiring separately.

| Operation | Peripheral payload sent | Bytes received | Source |
|---|---|---|---|
| chip_id | `00` (one byte) | 1; specified ID `50` | pp. 31, 40-41 |
| pressure_raw | `04` (one byte) | 3, registers `04..06` | pp. 32, 40-41 |

The historical USB proof used 0x77. The host still requires explicit address
selection because the datasheet permits two. Reading pressure registers clears
the pressure data-ready indication. This rule does not configure conversions;
raw bytes may reflect previous setup or reset state. Only these BMP388 reads
have bench evidence in this experiment; a description is not hardware detection.
