# Demonstration scenarios

A scenario describes how one or more node profiles are exercised and what an
integration test or assessor should observe. It does not duplicate hardware
settings from the node profile.

`first-prototype.json` preserves the historical multi-protocol demonstration;
it is not current C3 wiring or an accepted deployment profile. Use the
[reviewed bench profiles](../README.md#bench-profiles) for present tests.

Possible extensions include room cooling, bathroom ventilation, server-cabinet
protection and scheduled energy saving. Each needs supported drivers, reviewed
profiles and its own physical acceptance.
