# Historical AI evidence

The former timing-prediction and online datasheet experiments were removed from
active development when the project changed direction. Their dated records remain
in `qualification/` as historical evidence. Their paths and hashes describe
those original source revisions; they do not qualify current firmware.

The current runtime decision program and host Markdown compiler are documented in
[the runtime-rule guide](../experiments/runtime_rules/README.md). Reviewed source
Markdowns live in [datasheets](../datasheets/README.md).
