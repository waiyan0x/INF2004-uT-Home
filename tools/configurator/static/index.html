Preparing an idle board

I2C and radar detection need an empty hardware configuration; manual selections only prepare draft settings. To stop a running setup, first keep a copy of the profile you will restore. In a separate draft, empty the devices, interfaces, queues and rules lists, then use Validate and review → Apply & save. This also replaces the saved startup profile.
